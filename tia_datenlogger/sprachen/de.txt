# Die Datei muss UTF-8 kodiert bleiben. Gesucht wird im Ordner "sprachen" im Datenordner und im Programmordner.

@ Ein <b>Block</b> liest <i>Anzahl</i> aufeinanderfolgende Elemente eines <b>Arrays</b> ab dem <i>ersten Index</i> (wie in TIA Portal, z. B. 1 bei Array[1..100]) gemeinsam in einer Anfrage. Das Array ohne Index angeben, z. B. <code>Mess_DB.Werte</code>; das <i>Format</i> dient der Anzeige (dekodiert wird nach dem Typ, den die Steuerung meldet). Jedes Element wird zur Variable <code>Name[0]</code>, <code>Name[1]</code>, … und kann in Formeln verwendet werden. Im <b>Baum</b> unten lassen sich die <b>Namen der einzelnen Elemente</b> per Doppelklick ändern (leer = Standardname <code>Name[i]</code>). In der letzten Spalte des Baums kann jedes Element einem <b>anderen Diagramm bzw. einer anderen Y-Achse</b> zugeordnet werden (<i>wie Block</i> = Ziel des Blocks); gelesen werden alle Elemente weiterhin gemeinsam mit einer Anfrage.
