# Neue Sprache: diese Datei kopieren und nach dem Sprachkürzel benennen (z. B. fr.txt, it.txt, es.txt),
# oben hinter "Sprache:" den Namen der Sprache eintragen und hinter jedem ">" die Übersetzung schreiben.
#   @ = deutscher Originaltext (nicht ändern)     > = Übersetzung (leer lassen = deutscher Text bleibt)
#   \n = Zeilenumbruch. Platzhalter wie {0} oder {1:.1f} müssen in der Übersetzung erhalten bleiben.
#   & vor einem Buchstaben = Tastenkürzel im Menü (Alt + Buchstabe); && = ein einzelnes &-Zeichen.
# Die Datei muss UTF-8 kodiert bleiben. Gesucht wird im Ordner "sprachen" im Datenordner und im Programmordner.
# Umschalten: Menü "Sprache" (gilt nach einem Neustart).

@ Ein <b>Block</b> liest <i>Anzahl</i> aufeinanderfolgende Elemente eines <b>Array-Tags</b> ab dem <i>ersten Index</i> mit einer einzigen Anfrage (schneller als einzelne Variablen). Array-Tag ohne Index angeben, z. B. <code>Messwerte</code> oder <code>Program:Main.Temp</code>; das <i>Format</i> muss dem Datentyp des Arrays entsprechen. Jedes Element wird zur Variable <code>Name[0]</code>, <code>Name[1]</code>, … und kann in Formeln verwendet werden. Im <b>Baum</b> unten lassen sich die <b>Namen der einzelnen Elemente</b> per Doppelklick ändern (leer = Standardname <code>Name[i]</code>). In der letzten Spalte des Baums kann jedes Element einem <b>anderen Diagramm bzw. einer anderen Y-Achse</b> zugeordnet werden (<i>wie Block</i> = Ziel des Blocks); gelesen werden alle Elemente weiterhin gemeinsam mit einer Anfrage.
> A <b>block</b> reads <i>Count</i> consecutive elements of an <b>array tag</b> starting at the <i>first index</i> with a single request (faster than individual variables). Specify the array tag without index, e.g. <code>Messwerte</code> or <code>Program:Main.Temp</code>; the <i>format</i> must match the data type of the array. Each element becomes the variable <code>Name[0]</code>, <code>Name[1]</code>, … and can be used in formulas. In the <b>tree</b> below, the <b>names of the individual elements</b> can be changed by double-click (empty = default name <code>Name[i]</code>). In the last column of the tree, each element can be assigned to <b>another chart or another Y axis</b> (<i>as block</i> = target of the block); all elements are still read together with one request.

@ <b>Bedingung</b> wie eine Formel, z. B. <code>{Temperatur} &gt; 80</code>, <code>{Druck} &lt; 2 and {Pumpe} == 1</code>, <code>abs(ddt({Füllstand})) &gt; 5</code>. Wird sie wahr, <i>kommt</i> das Ereignis (ein Eintrag im Ereignisprotokoll), wird sie wieder falsch, <i>geht</i> es. <b>Meldetext</b>: <code>{Name}</code> wird durch den aktuellen Wert ersetzt (leer = Bedingung). <b>Verzögerung</b>: so lange muss die Bedingung ununterbrochen erfüllt sein. <b>Quittieren</b>: das Ereignis zählt in der Statusleiste des Loggers, bis es im Ereignis-Viewer quittiert wird.
> <b>Condition</b> like a formula, e.g. <code>{Temperatur} &gt; 80</code>, <code>{Druck} &lt; 2 and {Pumpe} == 1</code>, <code>abs(ddt({Füllstand})) &gt; 5</code>. When it becomes true, the event is <i>raised</i> (an entry in the event log); when it becomes false again, it <i>clears</i>. <b>Message text</b>: <code>{Name}</code> is replaced by the current value (empty = condition). <b>Delay</b>: the condition must be met continuously for this time. <b>Acknowledge</b>: the event is counted in the logger's status bar until it is acknowledged in the event viewer.
