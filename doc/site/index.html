What it does

Live trends

Several charts and pages, zoom, rulers, value table, bar graphs, Bool signals, offline view of recordings.

Databases & Grafana

CSV plus SQLite, MariaDB/MySQL, PostgreSQL/TimescaleDB, QuestDB, InfluxDB 3, VictoriaMetrics, Prometheus – with a generated Grafana dashboard.

Triggers & alarms

Event log with acknowledgement and notes, marks on the time axis, notifications via e-mail, Teams, Slack, webhook, ntfy or Telegram.

Recording by trigger

Pre- and post-trigger like an oscilloscope – only the interesting part is stored.

Analysis

XY chart, FFT, PID controller tuning from recorded step responses, computed variables with formulas, PDF reports per shift/day/week/month.

In the browser

Built-in web server with HTTPS and users: charts, rulers, export, events and process view on PC, tablet and phone.

Headless & Raspberry Pi

Runs as a service; touchscreen panel for network, Wi-Fi, time from the PLC and display dimming. Desktop clients connect over the network.

IO check

Commissioning aid: signal list, matrix, swapped wires, analog test points and protocol – also on the phone.

OPC UA server & MQTT

Provides the recorded values to SCADA and HMI systems, sends them to an MQTT broker (Home Assistant discovery, Node-RED) and records values from MQTT devices.

Try it in two minutes

Download the package for your system from the latest release, start PLC Datenlogger and click Demo – simulated values, no PLC needed. Or from source:

pip install -r requirements.txt
python src/plc_logger.py --demo
